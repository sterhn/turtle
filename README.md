# Черепашка Python

Простая веб-версия модуля `turtle` для уроков: ученики пишут программу, которая начинается с `from turtle import *`, и смотрят, как черепашка рисует.

Откройте `index.html` в браузере. Ничего устанавливать не нужно.

Команды: `forward`, `backward`, `left`, `right`, `penup`, `pendown`, `color`, `goto`, а также `circle`, `pensize`, `speed`, `begin_fill`/`end_fill`, `dot`, `setheading`, `hideturtle`, `write`. Работают переменные, `for`, `while`, `if` и `def`. Ошибки объясняются по-русски с номером строки и подсказкой.
